# General Demo Files & Prompts Library

This folder contains general-purpose documents, datasets, scripts, and prompt templates for everyday conversational and agentic workflows.

---

## 📂 Included Demo Files

1. **`meeting_notes_quarterly_review.md`**: Realistic corporate quarterly review meeting notes covering milestones, engineering updates, UX challenges, and assigned action items.
2. **`sales_leads_q3.csv`**: Sales pipeline dataset containing deal sizes, lead scores, industries, contact points, and closing dates.
3. **`research_summary_autonomous_agents.txt`**: Concise technical whitepaper excerpt explaining modern autonomous AI agent loops, deterministic tooling, privacy considerations, and interface simplicity.
4. **`customer_feedback.json`**: Structured customer sentiment dataset with feedback categories, star ratings, and feature requests.
5. **`sample_code_analysis.py`**: Clean Python script performing statistical calculations, outlier identification, and summary metrics.
6. **`prompts_library.json`**: Ready-to-run prompt templates paired with corresponding demo files for one-click testing.

---

## 🚀 Quick Testing Examples

- **Document Summarization:** Ask the assistant to summarize `meeting_notes_quarterly_review.md` and generate an executive bullet list.
- **Tabular Data Processing:** Ask the assistant to inspect `sales_leads_q3.csv`, calculate the win rate, and identify the top in-progress deals.
- **Code Review:** Ask the assistant to evaluate `sample_code_analysis.py` for mathematical edge cases and optimization ideas.
- **Privacy & Metadata:** Upload any of these files to see automatic local metadata stripping in action.
